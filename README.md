# peakwell-homepage

自社ホームページ

## プロジェクト構成

- `index.html` - トップページのマークアップ。
- `styles.css` - 全体のスタイルとレスポンシブ対応。
- `assets/images/` - ロゴとセクション用イラストを配置するディレクトリ。

## 使い方

1. `index.html` をブラウザで開くだけで閲覧できます。
2. ロゴやイラストを差し替える場合は、`assets/images/` 内のSVGファイル（例: `logo-peakwell.svg`）を任意の画像に置き換えてください。
3. 追加セクションやテキストは、`index.html` の該当箇所を編集してください。

## 連絡先リンクの更新

- 電話番号や住所などを変更したい場合は、`index.html` の「お問い合わせ」セクション内のテキストを編集してください。

## 開発メモ

- Google Fonts（Noto Sans JP / Poppins）を利用しています。オフライン環境で使用する場合はローカルにフォントを用意してください。
- ハンバーガーメニューはモバイルサイズで自動的に表示されます。
