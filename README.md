# Peakwell プロジェクト管理

複数プロジェクトを一覧管理するダッシュボードアプリケーション。

## 機能

- プロジェクト一覧ダッシュボード（ステータス別フィルタ・並び替え）
- プロジェクト作成・編集・削除
- タスク管理（追加・ステータス変更・削除）
- 進捗の自動計算（タスク完了率）
- 期限管理（超過アラート表示）
- メモ機能
- LocalStorageによるデータ保存

## 技術スタック

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4

## セットアップ

```bash
npm install
npm run dev
```

http://localhost:3000 でアクセス
