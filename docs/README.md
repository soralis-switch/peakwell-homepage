# PC↔スマホ連携ガイド

## 概要

このリポジトリの `docs/` フォルダを使って、**タスク管理**と**議事録**をPC・スマホの両方から管理できます。

## ファイル構成

```
docs/
├── README.md          ← このファイル（使い方ガイド）
├── tasks.md           ← タスク管理表
└── minutes/           ← 議事録フォルダ
    └── YYYY-MM-DD_タイトル.md
```

## 使い方

### PCから（Claude Code）

Claude Codeのチャットで自然言語で指示するだけ：

```
「タスク追加：来週の会議資料を準備する、期限は3/25」
「タスク3を完了にして」
「今日の議事録を作って。参加者は〇〇と△△。議題は...」
「タスク一覧を見せて」
「先週の議事録を見せて」
```

### スマホから（GitHub）

1. **ブラウザ**で `github.com/soralis-switch/peakwell-homepage` にアクセス
2. `docs/` フォルダを開く
3. ファイルをタップして閲覧
4. 鉛筆アイコン（✏️）をタップして編集も可能

**おすすめ**: GitHubモバイルアプリをインストールすると更に便利です。
- iOS: App Store で「GitHub」を検索
- Android: Google Play で「GitHub」を検索

## 運用ルール

### タスク管理
- 新規タスクは表の末尾に追加
- 完了したら「完了したタスク」セクションに移動
- ステータス: `未着手` / `進行中` / `完了` / `保留`

### 議事録
- ファイル名: `YYYY-MM-DD_タイトル.md`（例: `2026-03-18_定例会議.md`）
- テンプレートに沿って記入
- 決定事項とアクションアイテムは必ず記録
